# PictoStory

Application qui aide les enfants avec un trouble du spectre de l'autisme (TSA) à suivre en classe les histoires étudiées, en affichant des pictogrammes au-dessus du texte.

Objectifs :

- soutenir l'autonomie de l'enfant en rendant la lecture fluide et accessible ;
- lever les pièges des variations lexicales et des reprises de personnages (anaphores) ;
- alléger la charge cognitive pour que l'enfant se concentre sur le sens et le plaisir de comprendre ;
- favoriser l'inclusion, en suivant le même rythme que les camarades.

Le projet est en cours de construction.
